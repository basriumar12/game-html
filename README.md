# Portal Game Edukasi 3D: Asesmen Sumatif Tengah Semester (STS)

Platform media pembelajaran dan Asesmen Sumatif Tengah Semester (STS) berbasis web 3D interaktif untuk tingkat SMP dan SMA.

## 📁 Struktur Halaman:
- **`index.html`** : Halaman Portal Utama (Pilihan Masuk Game Edukasi).
- **`iceRealm/`** : Game Ice Realm Adventure (Adventure Platformer 2D: Rubah Oranye & Ice Guardian, Kristal Ungu, Golem & Kuis Edukasi).
- **`sntSMPgame/`** : Game Scratch Obby 3D (Asesmen STS SMP Kelas VII - 20 Soal).
- **`sntSMAgame/`** : Game CyberQuest 3D (Asesmen STS SMA Kelas X - 20 Soal Kriptografi & Python).
- **`petualanganPintar3D/`** : Game Petualangan Si Kecil (PAUD / TK - Alfabet & Hijaiyah).

## 🚀 Fitur:
- Kompatibel dengan **Cloudflare Pages** (Statis murni HTML, CSS, JavaScript & Three.js tanpa build step).
- Kontrol sentuh Virtual Joystick Analog untuk Smartphone/Tablet & Keyboard Desktop.
- Integrasi Papan Peringkat (Leaderboard) & Pengiriman Nilai Otomatis ke Google Sheets Guru.
- Cheatsheet & Kisi-kisi Terintegrasi di dalam game.
